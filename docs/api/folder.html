list

GET /folders

Operation ID: listFolders.

Authentication: API key in the query (token).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | fields | query | string | No | Comma-separated list of properties to return. GET /folders/{id}/notes

Operation ID: listFolderNotes.

Authentication: API key in the query (token).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | id | path | string | Yes | The item ID. | | fields | query | string | No | Comma-separated list of properties to return. Request only what you need. |

Responses

200: The item

application/json

Property Type Required Description
has_more boolean No True when a further page is available; pass the next page number.
items array of object No
items[].altitude number No
items[].author string No
items[].body string No The note body, in Markdown. May also contain HTML.
items[].created_time integer No When the note was created.
items[].id string No
items[].is_conflict integer No Tells whether the note is a conflict or not.
items[].is_todo integer No Tells whether this note is a to-do or not.
items[].latitude number No
items[].longitude number No
items[].markup_language integer No 1 for Markdown, 2 for HTML.
items[].parent_id string No ID of the notebook that contains this note. Change this ID to move the note to a different notebook.
items[].source_url string No The full URL where the note comes from.
items[].title string No The note title.
items[].todo_completed integer No When the to-do was completed.
items[].todo_due integer No When the to-do is due.
items[].updated_time integer No When the note was last updated.
items[].user_created_time integer No When the note was created. May differ from created_time as the user can set it.
items[].user_updated_time integer No When the note was last updated. May differ from updated_time as the user can set it.
404: No item with that ID
